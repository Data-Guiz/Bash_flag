# Niveau 10 — Script Bash (final)

**Thème :** Automatiser avec un script  
**Commandes à maîtriser :** `bash`, variables, conditions

---

## Mission

Félicitations, vous arrivez au **dernier niveau** !  
Le flag est révélé par le script `decode.sh` — à condition de lui passer le **bon argument**.

---

## Rappels rapides

| Élément | Rôle |
|---------|------|
| `bash script.sh` | Exécute un script Bash |
| `chmod +x script.sh` puis `./script.sh` | Rend le script exécutable |
| `$1`, `$2`… | Arguments passés au script |
| `if [ condition ]; then … fi` | Structure conditionnelle |

---

## Indices

1. Lisez `brief.txt` et ouvrez `decode.sh` avec `cat`.
2. Le script attend **un mot** en argument.
3. Indice : c'est le nom du shell que vous utilisez actuellement (`echo $0` ou `bash --version`).
4. Essayez : `bash decode.sh bash`
